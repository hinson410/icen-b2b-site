Product Overview

A mid-to-high volume platform with continuous loading

The BS-480 is Mindray’s mid-to-high volume chemistry analyzer, running a constant 400 tests per hour and up to 560 tests per hour with the ISE module. Mindray describes the software as conventional in design but easy to navigate, aimed at laboratories where staff rotate through the bench.

Capacity is the point of this model: 80 reagent positions and 90 sample positions, with 90 permanent glass cuvettes and an eight-step automatic wash. Reagent channels support R1, R2, R3 and R4 combinations, so four-reagent assays can run without manual intervention between steps.

Automation extends past measurement. The BS-480 performs automatic re-runs, automatic serum indexing and automatic dilution, and supports auto-reflexive testing so a result outside limits can trigger the follow-on assay defined in the profile. Mindray states daily maintenance takes about five minutes, and that reagents from several lots can be calibrated simultaneously.

Applications

  • Mid-to-high volume routine chemistry
  • Four-reagent assays needing R1 to R4 channels
  • Laboratories using auto-reflexive test profiles
  • Serum index screening before reporting

Who is this product for?

  • Mid-to-high volume hospital laboratories
  • Reference and regional laboratories
  • Laboratories consolidating several benches into one platform
  • Sites where operator rotation demands a simple interface

FAQ

Common questions about Mindray BS-480 Chemistry Analyzer

What is the throughput of the BS-480?

A constant 400 tests per hour, and up to 560 tests per hour when the ISE module is fitted.

How many reagents can be onboard?

80 reagent positions, with R1, R2, R3 and R4 channels so four-reagent assays can run automatically.

What does auto-reflexive testing mean here?

A result that falls outside the limits you define can trigger the follow-on assay in the same profile, instead of waiting for a member of staff to order the repeat.

How is carry-over controlled?

Mindray states carry-over below 0.05%, achieved with air-bubble elimination before washing and an eight-step automatic wash.

How much daily maintenance does it need?

Mindray states about five minutes of daily maintenance.

How does it compare with the BS-380?

The BS-480 runs 400 T/H against 300 T/H, has 80 reagent and 90 sample positions, adds R4 channels and auto-reflexive testing. The BS-380 remains the choice when 300 T/H is enough.
